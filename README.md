# WORLD OF DREAMS — Ultimate Browser Build

## تشغيل
- فك ضغط الملف.
- ارفع محتويات المجلد إلى GitHub ثم اربطه مع Vercel.
- لا يوجد Build Command ولا Install Command. Framework: Other.
- افتح رابط HTTPS الناتج من Vercel.
- يحتاج اتصال إنترنت لتحميل Three.js من jsDelivr CDN.

## التحكم
- WASD / الأسهم: الحركة والقيادة
- Shift: ركض
- Space: قفز
- E: دخول/خروج السيارة
- C: تبديل منظور أول/ثالث
- N: نهار/غروب/ليل
- M: إظهار/إخفاء الخريطة
- Escape: القائمة

## الميزات
مدينة ثلاثية الأبعاد مولدة برمجياً، منطقة ساحلية وحديقة وساحة مركزية، مبانٍ متعددة الطوابق ونوافذ، أشجار وأعمدة إنارة، شخصية قابلة للاختيار وتغيير لون الملابس، سيارات قابلة للقيادة، شظايا ومهمة وعملات ومستويات، خريطة مصغرة، حفظ محلي، وتحكم لمس أساسي.

## حدود واقعية
هذا إصدار متصفح متقدم قابل للعب، لكنه ليس لعبة AAA مكتملة:
- الشخصيات والسيارات والمباني مولدة برمجياً وليست نماذج بشرية/سيارات فوتوريالية مرخصة.
- لا يوجد حالياً Multiplayer أو حسابات أو حفظ سحابي.
- لا يوجد نظام تصادم متقدم أو قصة كاملة أو NPCs ذكية أو صوتيات.
- يجب اختباره على أجهزة فعلية ومتصفحات مختلفة قبل الإعلان عنه كلعبة منشورة.
- الرسوم ثلاثية الأبعاد قد تكون ثقيلة على بعض الهواتف.

لا تستخدم أو ترفع أصولاً لا تملك ترخيصها. يمكن إضافة نماذج GLB مرخصة لاحقاً دون تغيير فكرة المشروع.
